NixOS / nixpkgs

Pull request tracker

Follow a change from pull request to release channel.

Paste a NixOS/nixpkgs pull request link, or enter its number.

Optional GitHub token

The token is sent only to GitHub and kept in this page until you clear it or reload. No token is needed for public PRs.

    Each branch is checked independently. “Included” means it contains the PR’s merge commit. Hydra links show build progress.

    Runs entirely in your browser · Data from the GitHub API
